### Sperm Morphology Classification (Xception + CBAM) on SMIDS Dataset
*Jul 2025.* Deep learning pipeline for sperm morphology classification using attention mechanisms.

* Combined Xception CNN with CBAM attention to improve focus on diagnostically relevant regions.
* Trained and evaluated on 3,000 high-resolution microscopic images.
* Achieved 96.2% accuracy and 0.99 AUC with strong macro precision/recall/F1.
